# Review Cycles

This folder contains six internal review-and-revision cycles for the NeurIPS workshop manuscript.

- Cycles 01-03 focus on scientific positioning, methodology, and evidentiary clarity.
- Cycles 04-06 focus on acceptance risk, writing polish, presentation quality, and final submission readiness.
- Each `cycle_0X_review.md` file contains three detailed reviewer-style critiques.
- Each `cycle_0X_response.md` file records the concrete fixes that were actually made or the scoped rationale for not expanding claims.
